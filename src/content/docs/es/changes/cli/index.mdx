Novedades visibles para quien usa el CLI — `packages/cli` dentro del monorepo `aurora-catalyst` desde que se consolidó ahí (el repo independiente `aurora-catalyst-cli` está ahora congelado, solo con valor histórico). Los refactors internos, mejoras de rendimiento y corrección de bugs se omiten a propósito: este log se centra en lo que cambia _cómo se usa_ la plataforma. Cada entrada enlaza a la propuesta original en el repo fuente.

Las entradas se agrupan por el tag semver que las publica, las más recientes arriba. Los cambios archivados desde el último tag aparecen en **Sin publicar** hasta que se corte una nueva versión.
